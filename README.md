
# CodeAlpha Login and Registration System

## Project Description
A simple Login and Registration System developed using C++.

## Features
- New user registration
- Username and password validation
- Duplicate username detection
- User login authentication
- Credential storage using file handling
- Success and error messages

## Technologies Used
- C++
- Object-Oriented Programming basics
- File Handling
- if-else statements
- Loops and Functions

## How to Run
1. Download Login.cpp.
2. Open it in a C++ compiler.
3. Compile and execute the program.
4. Register a new account.
5. Login using registered credentials.
